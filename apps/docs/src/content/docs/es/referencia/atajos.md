## Globales

| Atajo | Acción |
| --- | --- |
| `?` | Mostrar esta ayuda |
| `Cmd/Ctrl + K` | Búsqueda global |
| `G luego A` | Ir a Agenda |
| `G luego P` | Ir a Pacientes |

## Agenda

| Atajo | Acción |
| --- | --- |
| `N` | Nueva cita |
| `T` | Ir a hoy |
| `←` / `→` | Día anterior / siguiente |
