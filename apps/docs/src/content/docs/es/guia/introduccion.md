Dentalpin es un software de gestión para clínicas dentales enfocado en **calma, legibilidad y seguridad clínica**. Esta documentación cubre tres grandes bloques:

- **Guía** — cómo poner la clínica en marcha y usar el día a día.
- **Referencia** — detalle por módulo (agenda, odontograma, facturación, reportes).
- **API** — pendiente, llegará con la versión 2.

## A quién va dirigida

- **Dentistas, higienistas y asistentes** — guías de uso clínico.
- **Recepción** — agenda, cobros, comunicaciones.
- **Administradores** — configuración, facturación electrónica, integraciones.

## Requisitos

- Navegador moderno (últimas dos versiones de Chrome, Safari, Firefox o Edge).
- Conexión estable; Dentalpin es una web app y funciona mejor con red.
- Para tablet en gabinete: iPadOS 16+ o Android 13+.
