Dentalpin is clinical practice management software focused on **calm, legibility and clinical safety**. These docs are split in three:

- **Guide** — how to get the clinic running and day-to-day workflows.
- **Reference** — per-module detail (calendar, odontogram, billing, reports).
- **API** — coming in v2.

## Who it's for

- **Dentists, hygienists and assistants** — clinical usage.
- **Front desk** — calendar, payments, communications.
- **Administrators** — configuration, e-invoicing, integrations.

## Requirements

- Modern browser (latest two versions of Chrome, Safari, Firefox or Edge).
- Stable internet connection; Dentalpin is a web app.
- Chair-side tablet: iPadOS 16+ or Android 13+.
