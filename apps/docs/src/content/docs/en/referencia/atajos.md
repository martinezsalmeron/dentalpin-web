---
title: Keyboard shortcuts
description: Global and per-module shortcuts in Dentalpin.
---

## Global

| Shortcut | Action |
| --- | --- |
| `?` | Show this help |
| `Cmd/Ctrl + K` | Global search |
| `G then A` | Go to Calendar |
| `G then P` | Go to Patients |

## Calendar

| Shortcut | Action |
| --- | --- |
| `N` | New appointment |
| `T` | Jump to today |
| `←` / `→` | Previous / next day |
